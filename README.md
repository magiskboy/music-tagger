# Music Tagger

A simple app for quickly editing song info (title, artist, album, year, genre, and more).

## How to use

1. Open the app and pick a music folder.
2. Edit tags directly in the list.
3. Click **Apply Selected** or **Apply All Dirty** to save.

## Download

Go to [Releases](https://github.com/magiskboy/music-tagger/releases) and grab the build for your computer (`v1.0.0`, `v1.1.0`, …):

| System | File |
| --- | --- |
| Windows | `MusicTagger-windows-x86_64.exe` |
| macOS (Apple Silicon) | `MusicTagger-macos-arm64` |
| Linux | `MusicTagger-linux-x86_64` |

Download and run — no install needed.
